# 損傷レベル基準表 v1

損傷レベル(1〜5)を、主観語(「ひどい」「やばい」)ではなく**観察できる事実の組み合わせ**で決めるためのルール。歩く人は事実を選ぶだけで、レベルはこの表から機械的に決まる。誰が歩いても同じレベルが出ることを目的とする。

- この基準は歩歩歩プロジェクト実測366件(2025-11〜12)の記述から起草した。各レベルの例文は実測の原文
- 国の定期点検の診断区分(Ⅰ〜Ⅳ)とは**別物**。参考であり、診断ではない
- 幹事の検品でレベルを上書きできる。上書きした場合は理由を記録する(基準表の改訂材料になる)

## 1. 歩く人が答える質問(すべて事実)

| 質問 | 選択肢 |
|---|---|
| Q1 なにが? | 道路の穴・ひび/ガードレール・さく/みぞ・ふた/点字ブロック/電気・ライト/そのほか(標識など) |
| Q2 どうなっている? | 種別ごとの状態語(下の表)から1つ |
| Q3 どのくらいの広さ? | 1かしょ/いくつか/ずっと続いている |
| Q4 人が通るところを ふさいでいる? | ふさいでいない/少し/半分以上 |
| Q5 足がはまりそうな穴・すき間がある? | ない/ある |

## 2. レベル判定ルール(共通)

| レベル | 条件 |
|---|---|
| 1 | 汚れ・軽い変形のみ。機能は保たれている(読める・立っている・平ら) |
| 2 | はっきりした変形・錆・ひび。機能はまだある |
| 3 | 大きな変形・傾き・欠け・段差。機能が落ちている(読みにくい・ぐらつく・つまずく) |
| 4 | 折損・脱落・穴・崩落が起きている。機能がほぼ失われている |
| 5 | レベル4の状態が「いくつか」以上(Q3)、**または** Q4=半分以上、**または** Q5=ある |

つまり: **状態(Q2)で1〜4が決まり、範囲(Q3)・通行阻害(Q4)・開口(Q5)が4を5に引き上げる。**

## 3. 種別ごとの状態語(Q2)と実測の例

### ガードレール・柵(防護柵・車止め含む)

| 状態語 | レベル | 実測の例 |
|---|---|---|
| さびている・よごれている | 1〜2 | 「支柱にも錆が進行」 |
| へこんでいる・まがっている | 2〜3 | 「ガードレールが大きく凹み、腐食が進行」 |
| かたむいている・ぐらつく | 3 | 「フェンス支柱が大きく傾き、全体の固定が弱くなっている」 |
| おれている・たおれている・とれている・穴があいている | 4 | 「接合部が外れ、パイプが支柱から脱落」「複数箇所で穴あき・破断」 |
| ↑が ずっと続いている/柵がない区間ができている | 5 | 「防護柵が長区間にわたり倒壊し…転落防止機能が喪失」 |

とがった部分が突き出ている場合(「鋭利な形状」)は+1。

### 道路の穴・ひび(舗装)

| 状態語 | レベル | 実測の例 |
|---|---|---|
| 細かいひびだけ・段差なし | 2 | 「亀甲状ひび割れ…段差や大きな陥没は見られず」 |
| ひびが広がり段差・沈下がある | 3 | 「複数箇所で陥没・段差が発生」 |
| はがれ・浮き・欠けで、つまずく段差 | 4 | 「割れ・欠け・浮き上がり…段差も発生」 |
| 穴状の陥没・広範囲の沈下 | 5 | 「局所的に陥没し、穴状に沈下」 |

### みぞ・ふた(側溝)

| 状態語 | レベル | 実測の例 |
|---|---|---|
| ひび・ずれ(すき間なし) | 2〜3 | 「縁石が割れ・欠損し、段差が形成」 |
| 割れ・崩れで中が見えている | 4 | 「縁石ブロックが大きく破損し、一部が脱落して側溝内部が露出」 |
| ふたがない・踏み抜きそうな開口部 | 5(Q5=ある) | 「蓋が完全に欠損し、大きな開口部が露出…踏み抜き事故の危険性が非常に高い」 |

### 点字ブロック

| 状態語 | レベル | 実測の例 |
|---|---|---|
| よごれ・軽い摩耗 | 2 | — |
| 欠け・摩耗が数枚 | 3〜4 | 「突起が激しく摩耗し、誘導機能が低下」 |
| 欠け・破損で誘導が途切れている | 5 | 「複数箇所で欠け・摩耗・破損しており、誘導面が不連続」 |

点字ブロックは利用者(視覚障害者)が代替手段を持たないため、「誘導が途切れる」=即5とする。

### 電気・ライト/標識(そのほか)

| 状態語 | レベル | 実測の例 |
|---|---|---|
| 角度ずれ・軽い変形(読める) | 1〜2 | 「設置角度のずれ程度…気づきレベル」 |
| 大きく曲がり読みにくい | 3 | 「表示面の一部が剥離。視認性が大きく低下」 |
| 根元から折れ・大きく傾き(倒れそう) | 4〜5 | 「根元部から折れ曲がっている…衝突や見落としの危険性が高い」 |
| 照明の支柱根元の腐食・ぐらつき | 4〜5 | 「照明ポール根元…」(倒壊リスク) |

「止まれ」など規制標識の視認性低下は交差点事故に直結するため、読めないレベルなら4以上。

## 4. 報告アプリとの対応

現行アプリの入力(なにが/どのくらい/あぶない3択)は、v2でこの基準表のQ1〜Q5に置き換える。移行までの間は、アプリの「🔴すぐあぶない=仮5/🟡そのうち=仮3/⚪わからない=仮2」を検品時にこの表で確定する。

## 5. AIの使い方(予定)

写真からQ2〜Q5をAIが推定し、幹事の検品で確定する(AI単独で確定しない)。精度は実測366枚のラベル済み写真との一致率で検証してから運用に入れる。
